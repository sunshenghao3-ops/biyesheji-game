# 平面休闲贪吃蛇游戏

基于用户提供的像素素材制作的平面休闲贪吃蛇网页游戏。

## 功能

- 18 × 18 像素网格场地
- 方向键 / WASD 控制移动
- 空格暂停，R 重新开始
- 食物轮换、连击加分、护盾道具
- 本局得分与最高分持久化
- 响应式深色像素街机界面

## 本地运行

`ash
npm install
npm run dev
`

生产构建：

`ash
npm run build
`
