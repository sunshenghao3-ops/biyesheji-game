## 运行

这是独立静态网页游戏，无需安装依赖或构建。通过静态 HTTP 服务器访问本目录的 index.html 即可。

例如，在本目录使用已安装的 Python 3 执行：

    python -m http.server 4181 --bind 127.0.0.1

随后访问 http://127.0.0.1:4181/ 。若从仓库根目录启动静态服务器，则访问 /micro-horror-snake/ 。

## 操作与规则

- 点击“开始游戏”进入游戏。
- 方向键或 WASD 移动，空格暂停或继续，R 重新开始。
- 手机可滑动游戏区域或点击方向按钮。
- 吞下祭品获得分数并增长，随长度增加逐步加速。
- 祭品依次为腐烂果实、血眼、心脏、头骨、幽魂灯、诅咒盒，分别获得 10、20、30、40、50、60 分。
- 幽魂灯可抵挡一次碰撞；普通情况下撞墙或撞到自身即结束。
- 最高分保存在当前浏览器的本地存储中。
