# 蓝白数独

双击 `index.html` 即可离线玩，无需安装依赖。也可以运行 `node serve.js` 后打开 http://127.0.0.1:4173 。

支持随机唯一解题目、三档难度、键盘和触屏输入、候选笔记、撤销、擦除、错误标记、三次提示、暂停计时、音效及完成反馈。难度按给定数字数量分档，并非专业解题技巧评级。

快捷键：1–9 填数，方向键移动，N 切换笔记，Ctrl/Cmd+Z 撤销，P 暂停，Delete/Backspace 擦除。新局和切换难度会开始新题；刷新页面不会保留进度。

视觉依据用户提供的素材；页头铅笔从原图裁切。原图保留在 assets/sudoku-reference.png，可在页面玩法窗口中查看。
