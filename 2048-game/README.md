# 2048 · 数字合成

一个根据素材视觉语言制作的 2048 浏览器小游戏：深蓝标题、暖白纸张底色、细灰网格与蓝色层级。

## 运行

直接打开 `index.html` 即可游玩，也可以在当前目录执行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 操作

- 方向键或 `W / A / S / D` 移动
- 手机/触控板在棋盘上滑动
- 支持撤销一步、重新开始
- 最高分自动保存在浏览器本地
